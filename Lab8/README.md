# 🏨 Rayal Park CLI

CLI-приложение для управления номерами отеля.

## 🚀 Команды

```bash
node app.js create "Luxury Suite" "Luxury" 130 4.9
node app.js read <id>
node app.js list
node app.js update <id> price=150
node app.js delete <id>
node app.js search
node app.js backup ./data ./backup
node app.js rename <id> "New Name"
